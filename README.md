Zip file contains all source files, including the .bat files required to generate the .exe application. May also contain unnecessary files, this is just all of the files that I used while creating SoulAnchor.

To start, run the Start.bat file, it will open SoulAnchor. Close this window and run the .exe file. The exe is mainly what you'll use to run the application and whatnot.

If the application ever gets corrupted, delete the .exe and reinstall by running the Start.bat file once more. Don't run any of the other files as this is handled by start.bat and the .exe


Coded in C# with a combination of bch and Windows Powershell.
